## 1 · Nuzzle 那个 50% 的数字（代码已改，只差部署）

**问题**：网站上同一个 case study 里，同一个数字有两种互相矛盾的说法。

| 位置 | 原文 | 对不对 |
|---|---|---|
| 首页卡片文案 | "when half of all returns happen" | ✅ 对 |
| 数据块 | "50% OF CAT RETURNS / happen in the first 30 days" | ✅ 对 |
| THE CHALLENGE 段落 | "Nearly 50% of adopted cats are returned within the first 30 days" | ❌ 错 |

错在哪：第三条的分母是「被领养的猫」，说的是「领养的猫里一半会被退回」。
正确的分母是「被退回的猫」，说的是「所有退回里，一半发生在头 30 天」。
两者差了非常多倍。面试官往下滚会先看到正确的数据块，再看到这句，当场就能发现对不上。

**已经改好了**（在 `claude/claude-code-mobile-4n30tw` 分支上）：

- `components/case-v2/nuzzle-case.tsx` 第 134 行
- `app/work-classic/nuzzle/nuzzle-classic.tsx` 第 324 行

  改成：`Half of all cat returns to shelters happen within the first 30 days of adoption.`
  后半句（bad cats / Expectation Gap 那段）原封不动。

- 顺带修了 `$32M` 那块的口径。原来写 `Per year (~127,000 cats returned)`，
  和旁边 `127K+ / within first 30 days after adoption` 的定义打架。
  统一成 `Per year (~127,000 returned in the first 30 days)`，
  这样 $250 × 127,000 ≈ $32M 也对得上。

**你回来要做的**：

```bash

git checkout claude/claude-code-mobile-4n30tw
# 起 dev server 看一眼 /work-classic/nuzzle 和 /v2 的 Nuzzle case
# 没问题就合回主分支，然后
npx vercel --prod
```

⚠️ 这台机器上没有 dev server，所以这两处改动**只做了代码层面的核对，没有跑过页面截图验证**。
文案长度变了几个字，理论上不影响排版，但你回来还是看一眼。
